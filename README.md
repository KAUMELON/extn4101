# Professional and Personal Skill Development

Online course book for **EXTN 4101 Professional and Personal Skill Development (1+2)**, B.Sc.–M.Sc. (Integrated) Biotechnology, College of Agriculture, Vellayani, Kerala Agricultural University.

Based on the lecture notes of Dr. Esakkimuthu M., Department of Agricultural Extension Education.

Built with [Quarto](https://quarto.org/). The rendered site is in `docs/` and is served by GitHub Pages at <https://kaumelon.github.io/extn4101/>.

```
quarto render
```
